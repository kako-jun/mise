# 何を作るか

mise（ミセ）は、個人・企業のサイトをカテゴリからたどって発見するディレクトリ型の検索エンジン。広告や大手サイトが多い検索に疲れた人が、まだ知らない独立サイトに出会える場を目指す。名前は「見せる」「店」と *mise en place* をかけている。本番は `https://mise.llll-ll.com`（[deploy.md](../operations/deploy.md)）。

## 世界観

- 旧 Yahoo! JAPAN のカテゴリ型画面（1996 年版）を参考にしたファイラー形式。階層を 1 段ずつ置き換えて表示し、パンくずで戻る。選択中の階層は URL に反映し、直接開く・戻る・進むに対応する。
- 背景に簡略化したワイヤーフレームの 3D 地球を置き、文字を前面に出す。サイト行の国旗にホバー（スマホはタップ）すると地球がその国・区画へ向く（[architecture.md](../design/architecture.md)）。
- 画面四隅に HUD（掲載総数、直近の日別登録数、この端末での操作ログ）を出す。実データと実際の操作だけを表示する（[ui.md](../design/ui.md)）。
- マスコットは MISE と MIKE の語感をかけた三毛猫。ロゴの文字の三毛猫模様として実装済み。キャラクターの絵そのものは未決。
- 日本語・英語、ライト・ダークの切替に対応し、選択はブラウザ内に保存する。既定言語は英語。

## 発見の機会の方針

- 人気や閲覧数を表示・ランキングしない。大手と埋もれたサイトの発見機会を平準化する。
- AI の使用有無を、マイナス評価や順位付けの根拠にしない。
- 既定の並びは「そのサイト自身の更新日」の新しい順（[ui.md](../design/ui.md#一覧検索結果の既定の並び)）。
- mise を訪れずに内容を閲覧するための公開 RSS や外部向け公開 API は設けない方針。ただし現在の `/api/*` はブラウザ用で、利用者が直接呼び出せる。外部アクセスの完全な防止は保証しない。

## 現在の範囲

実装済み: カテゴリ階層、検索（サーバー側の部分一致）、エンドレススクロール、ピックアップ、国旗・区画と地球の連動、日英切替、SEO の基本（軽量 SSR・sitemap）。収集は手元スクリプトで行い、結果を migration として D1 に投入している（[collection/](../collection/discovery-policy.md)）。

未実装: 申請の承認の自動反映、掲載サイトの再巡回（状態遷移）と定期実行（手元で動く発見パイプラインはあるが cron は未登録）、LLM による紹介文生成、サムネイルの公開（撮影の試験用スクリプトのみ）、縦フィード、審議コーナーなど。すべて [ideas/](../ideas/README.md) に整理している。
