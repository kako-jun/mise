# 載せる基準と分類の方針

mise に載せるサイトの基準。決定の経緯は [decisions.md](../decisions.md)。パイプラインでの具体的な規則と閾値は [pipeline.md](../collection/pipeline.md)。

## 載せる基準

**独立したサイト**を載せる。個人に限らず、小さな事業者・企業の公式サイト・EC・店・団体・学会・組合・NPO・大学や学校、大手のサイト、成人向けも載せてよい。

**拒否するのは次だけ**:

- 広告中心（広告のためのページ）
- 量産（アフィリエイト目的等）
- パーキング／ドメイン売却／サーバ初期ページ
- スパム
- 技術的に取れないもの（robots.txt 拒否・noindex・HTTP エラー・本文が極端に薄い・日本語パイプラインでは日本語でないもの）
- 官公庁の本体（層1の名簿で別に扱う。[public-bodies.md](../collection/public-bodies.md)）
- **更新が止まった個人サイト**（#129）。最後の更新の兆候が 3 年以上前の個人サイト（`site_kind=individual`）は、原則登録しない。兆候が見つからないもの・© の年だけが古いもの・個人かどうか不明なものは、更新停止の証拠ではないので保留にして人が見る。例外は次の 2 つだけ（これも迷うものは保留）:
  - **希少ジャンル**（`exempt=rare_genre`）: 同じ主題の代替がほとんど無い。
  - **有名・独立した解説のあるサイト**（`exempt=notable`）: 百科事典・データベース・長年の資料庫のように、サイト自体に独立した価値のある解説がある。
  例外の根拠は希少性か解説の有無だけで、人気・閲覧数・フォロワー数・知名度は根拠にしない。個人でないサイト（事業・団体・企業）は、更新が止まっていることを理由にしない。

「商業的」「大手」「成人向け」「組織」であること自体は拒否の理由にしない。属性（サイト種別 `site_kind`、成人向け `adult`）は台帳に記録するだけで、拒否に使わない（個人サイトの更新停止は上の条件でだけ、`site_kind` を使う）。

## 国と範囲

国は「範囲（scope）」としてディレクトリ全体にかける方針（カテゴリの木は 1 つ）。実装済み（[design/ui.md](../design/ui.md#範囲国)）。各サイトに運営者の所在国の旗を出し、国を範囲として切り替えられる。所在国は公開情報に明記されたものだけを採用し、ドメイン・言語・ホスティング・IP の所在では決めない。確認できなければ空（旗を出さない）。

## 共有サービス配下

ブログ・ショップ・ISP などの共有サービスは、**サービス本体のトップは載せる**。配下の個別ユーザー領域（`ユーザー名.jugem.jp` 等）は、拒否でなく**保留**にして基準の決定を待つ（Issue #50、未決）。無差別登録はしない。

## 公的機関

自治体・国の機関の公式サイトは載せる対象。公的機関の信頼できる一覧と、独立した 2 つ以上の出典でホスト名が一致したものだけを採用し、ドメイン名や HTTPS だけで公式と決めない。偽サイトを完全に排除できるとは保証せず、確認できない場合は公式扱い・自動掲載しない。

## 分類

- カテゴリは**主題**で分ける。そのサイトが何について書いているか、何を売り・教え・伝えているか。運営主体（企業・団体・個人サイト・店）では分けない（店は扱う品・サービスの主題、学校は教育、病院は健康）。運営主体は `site_kind` とタグで扱う。
- 木は 153 カテゴリ（トップ 15・第2階層 122・第3階層 16、2026-11-18 の #114 で旧 59 から入れ替え）。深さは最大 3 から始め、件数が増えた葉に子を足して育てる（成長則は [data-model.md](../design/data-model.md#カテゴリの木114-第1段0021)）。正本は `data/categories.csv`。
- 名前（日英）は mise が独自に付ける。国立国会図書館の [NDC 新訂10版の分類基準](https://www.ndl.go.jp/en/data/catstandards/classification_subject)、Wikipedia のカテゴリの構造、Curlie のトップの粒度は、主題の粒度を確かめる**参考**にとどめ、分類表の文言・説明文は転載しない（NDC 10 版は日本図書館協会の著作物で、自由利用できるとは確認できていない）。書籍用分類をそのままウェブサイトに適用して網羅を保証しない。
- 1 サイトは最大 3 カテゴリに所属できる。葉を優先して選び、合う葉が無いときだけ親に置く。
- 国と地域は木に入れない。国は範囲（`/jp/` など）で扱い、都道府県は範囲の第2階層として別に扱う（#114 第2段）。
- 官公庁・自治体は「行政・公的機関」の下に種別 7 葉（国の機関・独立行政法人・都道府県・市・特別区・町・村）を置き、台帳の種別から決定論で振る（LLM は使わない）。この 7 葉は成長則の対象外で、件数が増えたら子を足さず、第2段の都道府県の範囲で分ける。
- 件数は、そのカテゴリ自身と全子孫の所属サイトを数える。同じサイトが複数の子孫に属しても 1 件。空カテゴリは 0 件。D1 から API で集計する。
