# 載せる基準と分類の方針

mise に載せるサイトの基準。決定の経緯は [decisions.md](../decisions.md)。パイプラインでの具体的な規則と閾値は [pipeline.md](../collection/pipeline.md)。

## 載せる基準

**独立したサイト**を載せる。個人に限らず、小さな事業者・企業の公式サイト・EC・店・団体・学会・組合・NPO・大学や学校、大手のサイト、成人向けも載せてよい。

**拒否するのは次だけ**:

- 広告中心（広告のためのページ）
- 量産（アフィリエイト目的等）
- パーキング／ドメイン売却／サーバ初期ページ
- スパム
- 技術的に取れないもの（robots.txt 拒否・noindex・HTTP エラー・本文が極端に薄い・日本語パイプラインでは日本語でないもの）
- 官公庁の本体（層1の名簿で別に扱う。[public-bodies.md](../collection/public-bodies.md)）

「商業的」「大手」「成人向け」「組織」であること自体は拒否の理由にしない。属性（サイト種別 `site_kind`、成人向け `adult`）は台帳に記録するだけで、拒否に使わない。

## 国と範囲

国は「範囲（scope）」としてディレクトリ全体にかける方針（カテゴリの木は 1 つ）。現状は各サイトに運営者の所在国の旗を出すところまでが実装済みで、範囲の切替は構想（[ideas/scope-and-search.md](../ideas/scope-and-search.md)）。所在国は公開情報に明記されたものだけを採用し、ドメイン・言語・ホスティング・IP の所在では決めない。確認できなければ空（旗を出さない）。

## 共有サービス配下

ブログ・ショップ・ISP などの共有サービスは、**サービス本体のトップは載せる**。配下の個別ユーザー領域（`ユーザー名.jugem.jp` 等）は、拒否でなく**保留**にして基準の決定を待つ（Issue #50、未決）。無差別登録はしない。

## 公的機関

自治体・国の機関の公式サイトは載せる対象。公的機関の信頼できる一覧と、独立した 2 つ以上の出典でホスト名が一致したものだけを採用し、ドメイン名や HTTPS だけで公式と決めない。偽サイトを完全に排除できるとは保証せず、確認できない場合は公式扱い・自動掲載しない。

## 分類

- 現行は 14 のトップカテゴリとその子（`migrations/0001_initial.sql`）。旧ポータル風の試作であり、世界の主題を網羅した体系ではない。
- 新設は国立国会図書館の [NDC 新訂10版の分類基準](https://www.ndl.go.jp/en/data/catstandards/classification_subject) と [NDC 一覧](https://crd.ndl.go.jp/reference/ndcmaster/index.php) を照合して候補を作り、現行カテゴリとの対応・利用条件・分類の重複を確認してから決める。書籍用分類をそのままウェブサイトに適用して網羅を保証しない。
- 1 サイトは複数カテゴリに所属できる。運営主体や独自ドメインなど主題以外はタグに分ける。
- 件数は、そのカテゴリ自身と全子孫の所属サイトを数える。同じサイトが複数の子孫に属しても 1 件。空カテゴリは 0 件。D1 から API で集計する。
- 官公庁のカテゴリ（新設するか既存の地域に置くか）は台帳づくりの後に提案して合意する（未決）。
