# サーフモード・縦フィード（構想・モックアップ中）

Issue #52。**実装済みではない**。モックアップは PR #54（ドラフト、未マージ）で、`?view=feed` で触れる試作。既定表示は変えていない。

## 狙い

縦スクロールの SNS やショート動画のように「ダラダラ見てしまう」魅力を、従来の Web ページ巡回（ネットサーフィン）で出す。ネットサーフィンの復興が mise の核という位置づけ。

## 考え方

- 「次へ」の気持ちよさが核。1 つ見終わったら次が自然に出る。選ぶコストを下げる。
- **サーフモード**: 範囲（国）・カテゴリを指定し、ほぼランダム（新着・更新を少し優遇）に次のサイトへ進む。キー（j/k, ↓）・スワイプ・ボタンで次へ・前へ。戻って来られる。
- **縦フィード**: サイトを 1 枚のカード（プレビュー画像・サイト名・一言・国旗/区画・タグ）として縦に流す。カードごとにスナップ。「開く」ボタン。
- **リンクをたどる**: そのサイトが外部リンクしている掲載サイトを提示する（ウェブリング的）。発見パイプラインが持つ外部リンクを使う。
- **開き方**: 埋め込み可のサイトは画面内のパネル、不可は新しいタブ。いきなりブラウザは作らない（[browser-and-thumbnails.md](browser-and-thumbnails.md)）。
- **守るもの**: 依存を煽る暗いパターン（通知・連続報酬の演出・終わりが見えない設計）を目的にしない。終わりを見せる（あと何件）選択肢も持つ。

## 方針（kako-jun 2026-11-13）

縦フィードを**メインの表示**にし、従来のディレクトリ表示は表示の切替で選べる形にする。カテゴリごとの従来ページ（URL・SSR のリンク）は検索エンジン向けに残し、入口のフィードも先頭数件はサーバー出力に含める。絞り込み（カテゴリ・範囲）はフィード上部に控えめに置き、従来ビューへの切替は常に見える位置に置く。地球儀は背景で、カード表示中はその国・県に連動する。サムネイルが前提で、未取得はサイト名＋国旗のカード。

## 長い紹介文

サイト名と一言紹介に加え、「どんなサイトで、どんな作者で、何が一芸か」まで書いた 200〜400 字程度の紹介文を、ショート動画のコメントのようにサムネイルに重ねて読める。`long_description_ja` / `long_description_en` を LLM 工程（[llm-judging.md](llm-judging.md)）で生成する案。事実だけ（サイト自身の記載に根拠があるもの）で、根拠の引用を持ち、推測・誇張・評価の捏造をしない。根拠が薄ければ短く済ませるか null。成人向け属性があるものは中立・婉曲に。About 系ページの追加取得（同一ホスト、robots 遵守、1 サイト最大 2 ページ）が前提。

## モックアップで試していること

カードは横長の 1 枚を上部に、同じ絵を拡大・ぼかして背景に、下半分は暗いスクリム＋文字。サムネ未取得は ID から決まる三毛猫模様＋頭文字。j/k 移動、カードが画面に入ると地球が国/県へ向く、日本のみ絞り込み、末尾の終了カード、従来表示への切替、長文のタップ展開。触って決める点は、カード要素の過不足、重み（新着の優遇）と並び、ぼかし・スクリム濃度、長文の折りたたみ行数、遷移。長文はモック用のダミー文で本番データではない。先頭数件の SSR、ページング、実サムネでの読みやすさは未確認・未実装。

## 見たサイトの累計（Issue #58、モックで試作）

右上に `SEEN 000128` のようなスコア風の表示（等幅・ゼロ埋め6桁）。「見た」はカードが画面の 60% 以上で 1.5 秒以上表示されたとき（素通りは数えない）。重複を除いた累計で、増える一方（ストリーク・公開ランキングは作らない）。保存は端末内のみ（localStorage、サイト ID → 初めて見た日時、バージョン付き。JSON の書き出し・読み込みあり）。増えたとき数字が一瞬ふくらむだけで、音・通知なし（reduced-motion では数字の切替のみ）。タップで詳細（月ごと・国別・カテゴリ別、次の節目までのバー）。節目（10/50/100/300/1000）に達すると、ロゴの横に子猫が 1 匹ずつ並ぶ（控えめ・一瞬・クリックで省略）。判定時間・節目は feed.js 冒頭の定数。

## 試作ビュー `?view=feed`（本番に公開。noindex）

PR #54 で試作ビューとして本番に載せる（既定表示は変えない。`?view=feed` が無ければ従来どおり）。読み込みは `public/index.html` の小さなフックが `?view=feed` のときだけ `feed.css` / `feed.js` を足す。

- **データ**: `/api/categories`・`/api/scopes` と、`/api/sites?limit=100` を cursor でたどって最大 1,000 件を読み、絞り込み（範囲・カテゴリ）とおまかせの並びはブラウザ側で行う。範囲は「全世界・国・県」を `/api/scopes` から作る（`?scope=jp` / `jp-13`）。1,000 件を超える分は出ない（試作の制限。本実装ではサーバー側の絞り込みとページングにする）
- **CSP**: `script-src 'self'` ＋インラインスクリプトのハッシュ、`style-src 'self'`、`img-src 'self' data:`、`connect-src 'self'` のまま違反なく動く。第三者へはアクセスしない（サムネは同一オリジンの絶対パスのみ。無ければ三毛猫の代替絵）。`tests/feed-view.test.mjs` が静的に守る
- **SEO**: `?view=feed` は `<meta name="robots" content="noindex,follow">` を出し（`src/seo.js`）、canonical は通常ページを指す。sitemap には入れない
- **試作の印**: 上部の右に小さく `BETA`（日本語は「試作」）
- **端末内保存**: 見たサイト累計・言語・テーマ・新しいタブ設定は localStorage を try/catch で包み、使えなくても動く
- **実サムネ**: `/thumb/` の配信が入るまで実サムネは出ない（`public/` に画像を置かない規約のため、以前のローカル専用の `_mock-thumbs` 読み込みは廃止した）
