# サーフモード・縦フィード（構想・モックアップ中）

Issue #52。**実装済みではない**。モックアップは PR #54（ドラフト、未マージ）で、`?view=feed` で触れる試作。既定表示は変えていない。

## 狙い

縦スクロールの SNS やショート動画のように「ダラダラ見てしまう」魅力を、従来の Web ページ巡回（ネットサーフィン）で出す。ネットサーフィンの復興が mise の核という位置づけ。

## 考え方

- 「次へ」の気持ちよさが核。1 つ見終わったら次が自然に出る。選ぶコストを下げる。
- **サーフモード**: 範囲（国）・カテゴリを指定し、ほぼランダム（新着・更新を少し優遇）に次のサイトへ進む。キー（j/k, ↓）・スワイプ・ボタンで次へ・前へ。戻って来られる。
- **縦フィード**: サイトを 1 枚のカード（プレビュー画像・サイト名・一言・国旗/区画・タグ）として縦に流す。カードごとにスナップ。「開く」ボタン。
- **リンクをたどる**: そのサイトが外部リンクしている掲載サイトを提示する（ウェブリング的）。発見パイプラインが持つ外部リンクを使う。
- **開き方**: 埋め込み可のサイトは画面内のパネル、不可は新しいタブ。ブラウザを作るわけではない（[browser-and-thumbnails.md](browser-and-thumbnails.md)）。
- **守るもの**: 依存を煽る暗いパターン（通知・連続報酬の演出・終わりが見えない設計）を目的にしない。終わりを見せる（あと何件）選択肢も持つ。

## 方針（kako-jun 2026-11-13）

縦フィードを**メインの表示**にし、従来のディレクトリ表示は表示の切替で選べる形にする。カテゴリごとの従来ページ（URL・SSR のリンク）は検索エンジン向けに残し、入口のフィードも先頭数件はサーバー出力に含める。絞り込み（カテゴリ・範囲）はフィード上部に控えめに置き、従来ビューへの切替は常に見える位置に置く。地球儀は背景で、カード表示中はその国・県に連動する。サムネイルが前提で、未取得はサイト名＋国旗のカード。

## 長い紹介文

サイト名と一言紹介に加え、「どんなサイトで、どんな作者で、何が一芸か」まで書いた 200〜400 字程度の紹介文を、ショート動画のコメントのようにサムネイルに重ねて読める。`long_description_ja` / `long_description_en` を LLM 工程（[llm-judging.md](llm-judging.md)）で生成する案。事実だけ（サイト自身の記載に根拠があるもの）で、根拠の引用を持ち、推測・誇張・評価の捏造をしない。根拠が薄ければ短く済ませるか null。成人向け属性があるものは中立・婉曲に。About 系ページの追加取得（同一ホスト、robots 遵守、1 サイト最大 2 ページ）が前提。

## モックアップで試していること

カードは横長の 1 枚を上部に、同じ絵を拡大・ぼかして背景に、下半分は暗いスクリム＋文字。サムネ未取得は ID から決まる三毛猫模様＋頭文字。j/k 移動、カードが画面に入ると地球が国/県へ向く、日本のみ絞り込み、末尾の終了カード、従来表示への切替、長文のタップ展開。触って決める点は、カード要素の過不足、重み（新着の優遇）と並び、ぼかし・スクリム濃度、長文の折りたたみ行数、遷移。長文はモック用のダミー文で本番データではない。先頭数件の SSR、ページング、実サムネでの読みやすさは未確認・未実装。
