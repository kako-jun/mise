# サーフモード・縦フィード

Issue #52。新着・カテゴリ別の縦ビューの入口と表示は [UI の仕様](../design/ui.md#新着と縦ビュー) を参照。

## 狙い

縦スクロールの SNS やショート動画のように「ダラダラ見てしまう」魅力を、従来の Web ページ巡回（ネットサーフィン）で出す。ネットサーフィンの復興が mise の核という位置づけ。

## 考え方

- 「次へ」の気持ちよさが核。1 つ見終わったら次が自然に出る。選ぶコストを下げる。
- **サーフモード**: 範囲（国）・カテゴリを指定し、ほぼランダム（新着・更新を少し優遇）に次のサイトへ進む。キー（j/k, ↓）・スワイプ・ボタンで次へ・前へ。戻って来られる。
- **縦フィード**: サイトを 1 枚のカード（プレビュー画像・サイト名・リンク先のホスト名〔小さく 1 行。[design/ui.md](../design/ui.md#ファビコン)〕・一言・国旗/区画・タグ）として縦に流す。カードごとにスナップ。「開く」ボタン。
- **リンクをたどる**: そのサイトが外部リンクしている掲載サイトを提示する（ウェブリング的）。発見パイプラインが持つ外部リンクを使う。
- **開き方**: 埋め込み可のサイトは画面内のパネル、不可は新しいタブ。いきなりブラウザは作らない（[browser-and-thumbnails.md](browser-and-thumbnails.md)）。
- **守るもの**: 依存を煽る暗いパターン（通知・連続報酬の演出・終わりが見えない設計）を目的にしない。終わりを見せる（あと何件）選択肢も持つ。

## 画面の方針

新着を縦ビューの主な入口にする。各カテゴリの箇条書きでも、そのフォルダの縦ビューに切り替えられる。縦ビューの上部には帯を置かず、背景の上に、箇条書きへ戻る矢印・左右中央の検索欄（スマホは矢印とカウンターのあいだの 1 行）・右上の猫サーフィンと見たサイト数を重ねる（#198）。

## 長い紹介文

サイト名と一言紹介に加え、「どんなサイトで、どんな作者で、何が一芸か」まで書いた 200〜400 字程度の紹介文を、ショート動画のコメントのようにサムネイルに重ねて読める。`long_description_ja` / `long_description_en` を LLM 工程（[llm-judging.md](llm-judging.md)）で生成する案。事実だけ（サイト自身の記載に根拠があるもの）で、根拠の引用を持ち、推測・誇張・評価の捏造をしない。根拠が薄ければ短く済ませるか null。成人向け属性があるものは中立・婉曲に。About 系ページの追加取得（同一ホスト、robots 遵守、1 サイト最大 2 ページ）が前提。

## カード

カードの上部にサムネイル、背景に同じ絵をぼかして表示し、下部の文字に薄い影を重ねる。サムネ未取得は ID から決まる三毛猫模様と頭文字。最後には終了カードを表示する。

## 見たサイトの累計（Issue #58）

「見た」はカードが画面の 60% 以上見えて現在のカードに切り替わった瞬間（#277。滞在待ちなし。連続送り・通過しただけのカードは数えない（指・ホイールは止まって揃った瞬間）。自動送り #199 で進んだカードも数える。放置で全件見たことになりうるが、仕様として許容）。累計は重複を除き、端末内にだけ保存する。最後のカードから件数と内訳（月ごと・国別・カテゴリ別）を確認でき、JSON の書き出し・読み込みにも対応する。

## 自動送り（Issue #199）

一定時間たつと自動で次のサイトへ進む。1 枚 **12 秒**（`feed.js` の `AUTO_ADVANCE_MS`）。進行は画面下端に貼り付く高さ 4px のバー（スマホは全幅、PC はカード列幅 520px）（`.f-progress`。`transform: scaleX` だけを毎フレーム更新。カードが変わるとリセット）で見せる。

- **オン/オフは常に見える**: 上下ボタンの下の「自動 / 入・切」（`.f-auto`。文字だけ・周囲と同じ 44px の丸ボタン・`aria-pressed`。`aria-label` は固定の「自動送り」で状態は `aria-pressed` だけ。0 件では隠す）。既定オン、`prefers-reduced-motion` のときは既定オフ。選択は localStorage（`mise-feed-auto-v1`）に保存。右下は #227 のため空けてある。
- **止まる条件**: 手動の wheel / touch / pointerdown / keydown の直後（scroll は自動送り自身でも出るので使わない）、「もっと見る」展開中、詳細パネルが開いている間、検索欄にフォーカス中、タブ非表示、表示中カードのリンク/ボタンの hover・キーボードフォーカス。止まっている間はバーを薄くする。
- **再開**: 手動操作・停止が解けてから 4 秒（`AUTO_RESUME_MS`）無操作なら、12 秒を最初から数え直す（解けた直後に即ジャンプしない）。
- **末尾**: 終了カードでは止まり、巻き戻さない。バーも隠す。
- **タブ復帰**: ブラウザは非表示中 rAF を止めるので、`tick` は前フレームから 1 秒超の隙間を「保留」とみなし、`visibilitychange` でも操作扱いにして、復帰後 4 秒待ってから 0 から数え直す。オフ・終了カード・0 件では rAF ループを止める。
- **移動**: 既存の `step(+1)` を使う（scroll-snap・#196 の地球休止・「見た」判定・上下ボタンの現在位置と同じ経路）。時間の進みは `feed-lib.js` の `makeAutoAdvance`（純関数。`tests/feed-view.test.mjs` で検証）。

## データ取得と表示

読み込みは `public/index.html` のフックが `?view=feed` のときだけ縦ビュー用 CSS と JavaScript を足す。読み込み失敗、または 10 秒たっても `#feed` が現れないときは通常表示に戻る。

- **データ**: `/api/categories` で階層を解決し、`/api/sites` へ範囲と末端フォルダの ID を渡す。新着は `category=recent`。一度に最大 100 件、合計 500 件まで取得する。ページ番号付きのフォルダは最初に箇条書きと同じ 40 件を取得し、次からカーソルでたどる。続きがある場合や一部の取得に失敗した場合、最後のカードから箇条書きへ移動できる。フォルダの箇条書きでは、表示済み件数の次の行を `#site-row-N` で示す。以前の `?cat=`・`?scope=`・`?sort=` リンクも開ける。
- **描画**: 最初の 100 枚を描き、残りは 100 枚ずつ足す。`.f-card` は `content-visibility: auto`（高さ固定）で画面外の中身を描かない。読み込み中は「読み込み中…」を出す。
- **長文**: `long_description_*` が無いカードは長文欄を出さない。ダミー文は開発用の `?mock=1` のときだけ。
- **通常 UI のデータ取得**: 読み込み失敗時に通常画面を表示できるよう、縦ビューでも `app.js` の初期化が裏で動く。
- **安全**: 「開く」リンクは http(s) の URL だけ（`javascript:` などは出さない）。サムネは同一オリジンの絶対パスのみ（`//host`・`/\host` は不可）。「見た」JSON の読み込みは 1MB まで、キーは ID の形のみ。
- **CSP**: `script-src 'self'` ＋インラインスクリプトのハッシュ、`style-src 'self'`、`img-src 'self' data:`、`connect-src 'self'` のまま違反なく動く。第三者へはアクセスしない（サムネは同一オリジンの絶対パスのみ。無ければ三毛猫の代替絵）。`tests/feed-view.test.mjs` が静的に守る
- **SEO**: `?view=feed` は `<meta name="robots" content="noindex,follow">` を出し（`src/seo.js`）、canonical は通常ページを指す。sitemap には入れない。
- **端末内保存**: 見たサイト累計・言語・テーマ・新しいタブ設定は localStorage を try/catch で包み、使えなくても動く。
