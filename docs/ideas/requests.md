# 推薦・取り下げ・訂正の申請（構想）

Issue #4・#29。**未実装**。サイト推薦のリンクは「準備中」を出すだけで、受付も保存もない。

## 方針（kako-jun 指示 2026-11-13）

- **推薦（載せて）・取り下げ（載せないで）・訂正は、同じ「申請」**として 1 つの受付基盤・同じ状態遷移で扱う。案: `type`（add / remove / correct）、`status`（pending / approved / rejected）、受付日時、対象 URL、理由、連絡先。
- **申請は依頼であって、叶うとは限らない**。承認・却下は管理者が判断する。画面・docs にもその旨を明記し、「申請すれば必ず載る/外れる」と誤解させない。
- **本人証明はサイト外で行う**。mise 側にトークン設置などの確認機構は作らない。管理者がサイト外の手段（連絡先経由の返信、公開されている運営者の連絡手段など）で確認する。そのため連絡先は必須にし、保持期間を決める。確認が取れるまで掲載状態は変えない（推薦は未掲載のまま、取り下げは掲載のまま）。
- 例外: robots.txt の Disallow・noindex など、運営者が自サイトに出している意思表示は「申請」ではなく収集時の遵守事項として従来どおり尊重し、巡回時に外す/収集しない。
- 公開 API は作らない。受付のみ。
- X への言及は本人による任意操作とし、自動投稿しない。
