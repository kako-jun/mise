# 証券取引所の比喩・状態遷移・審議コーナー・初期発見（構想）

Issue #53・#55・#2。**いずれも未実装**。用語の定義は [glossary.md](../glossary.md#証券取引所の比喩)。

## 比喩の統一（kako-jun 2026-11-13）

mise の比喩は証券取引所で統一し、画面の名称・文言・docs をこの用語に揃える。新規掲載=新規上場、掲載=上場、一時停止=売買停止、閉鎖の疑い=監理ポスト（監理銘柄）、却下・掲載終了=上場廃止（整理ポスト）。「管理ポスト」ではなく「監理ポスト」。

## 掲載サイトの状態遷移（Issue #2・#53 の設計案）

到達不能を削除でなく状態遷移で扱う。状態: `candidate` / `listed` / `down` / `long_down` / `suspect` / `deferred` / `rejected` / `removed`（取り下げ承認）。遷移と理由・日時は履歴として保存する。

- 巡回で到達できなくなった掲載サイトは**削除しない**。`down`（売買停止）にして、フィード・一覧・検索・sitemap から外す（リンク切れを見せない）。再確認予定日・連続失敗回数・直近のエラー種別（DNS/接続/HTTP 5xx/証明書/タイムアウト）を持つ。
- 再確認で到達でき、内容が同一サイトのままなら `listed` に自動で戻す。履歴を残す。
- 一定期間（例: 連続失敗が数回かつ数十日）で `long_down`（閉鎖の疑い）に移し、合議にかけて保留（継続監視）か却下（掲載終了）を決める。**自動では削除しない**。
- 復活後にパーキング/売却ページ/別内容（タイトル・言語・主題が大きく変わる）になっていたら自動復帰せず、`suspect` として合議・人の確認へ（リンク先の悪用を防ぐ）。
- 判定は決定論（HTTP/DNS/証明書/パーキング検出/タイトル・言語の変化）が先で、合議は曖昧なものだけ。

## 審議コーナー（Issue #53）

載せていない候補・保留・取り下げ申請・売買停止/監理ポストのサイトを公開し、LLM による判定の文章と理由を載せる画面。

- **3 匹の猫**の合議。MAGI そのものの名前・設定・見た目は使わず（作品の固有表現）、mise の三毛猫に合わせて 3 匹が投票する。観点: ①独立性と質（広告中心・量産・パーキング・スパムでないか）②安全と法（なりすまし・著作権・成人向けの扱い・個人情報）③読者にとっての発見の面白さ。各自 承認/保留/却下＋短い理由。2/3 以上で決定、割れたら「会議中（保留）」として人が判断。3 体は指示文とモデルを変えて判断が割れる余地を残す。
- 画面: 状態別の一覧（候補・載せている・保留・却下・取り下げ申請）、各サイトに 3 票と理由文。意見が割れたものは目立たせる。
- 公開の配慮: ①理由は事実の言い方（「広告の割合が高い」等）にし、レッテル（「スパム」）を断定しない。公開は表示名・ホスト名のみ、異議申し立て窓口（[requests.md](requests.md)）を併記 ②取り下げ申請は申請者を特定できないよう、件数・状態・一般的な理由のみ ③成人向けは題材の詳細を書かず属性のみ ④却下サイトの再掲載・取り下げ後の扱いも明記。
- データ: 判定結果は候補台帳に votes（3 体の id・票・理由・モデル・日時・入力ハッシュ）として保存し、D1 には公開してよい項目だけを入れる。
- 依存: LLM 判定工程（[llm-judging.md](llm-judging.md)）の評価、申請の基盤、候補台帳。予算ガードは共通利用。

## 初期発見の喜び（Issue #55）

小さなサイトを流行る前から見つけていた、というユニコーン株投資のような喜びを、あとから確かめられる仕組み。ランキングで流行を煽るのではなく、**個人の発見の記録**として楽しむ。PR は出ていない（検証前）。

- 発見時点の注目度スナップショット（客観・決定論）: 掲載した時点とその後の定期再測定で、外部の客観指標を記録する。候補: Common Crawl ホストグラフの入次数の推移、Wayback の初出日、サイトの更新日の推移。**mise 自身の閲覧数は使わない**。
- ウォッチリスト: 利用者がサイトを保存すると、保存日時とその時点の注目度が記録される。アカウント不要でまず端末のローカル保存。公開しない・順位をつけない。
- あとから分かる喜び: 注目度が後に伸びたら「あなたが見つけたときは被リンク 3 ホスト、今は 2,400 ホスト」のように控えめに表示し、「早期発見」バッジ。通知で煽らない。
- 新規上場コーナー: 最近掲載された（まだ注目度が低い）サイトを一覧する。縦フィードと連動。
- 公平性: 公開のランキング・リーダーボードは作らない。人気で並びを優遇しない。
- 未決: 指標の取得元と更新頻度（Common Crawl は数か月ごと）、複数端末の同期、「早期発見」の閾値。最初の検証は、掲載済みサイトで Common Crawl の入次数が時系列で取れるかの小さな確認。
