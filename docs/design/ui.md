# 画面の仕様

実装済みの画面の挙動。コードは `public/app.js`・`public/index.html`・`public/style.css`。国旗・区画の表示と地球の連動は [architecture.md](architecture.md#国旗と地球の連動)。

## カテゴリ階層と検索

- カテゴリを選ぶと前の階層を置き換え、直下のカテゴリとサイトだけを表示する。パンくずで上位に戻れる。
- 階層は URL の `?category=<親ID>&category=<子ID>` に反映し、直接開く・リロード・戻る/進むで復元する。日本語名を使う旧 URL は ID に変換し、無効な値はトップに戻す。複数カテゴリへの所属と、いま表示している 1 本の階層パスは別の概念。
- 検索は、取得済みのサイトデータ（名前・日英の紹介文・URL）をブラウザ内で絞り込む。タグは検索対象ではない。検索インデックスはない。`?q=` で開くと検索結果を表示する。
- サイト推薦のリンクは「準備中」の案内を出すだけ（受付は未実装。構想は [ideas/requests.md](../ideas/requests.md)）。

## 一覧・検索結果の既定の並び

零細の個人サイトの更新が埋もれないよう、既定は「そのサイト自身の更新日」の新しい順。`ORDER BY COALESCE(source_updated_at, registered_at) DESC, id`（日時が読めない/NULL は末尾）。更新日が不明なサイトは mise への登録日で代用する（新規登録を新着扱いにする）。今日登録した更新日不明のサイトは、更新日が数か月前の既存サイトより上に並ぶ。

定義は `src/seo.js` の `SITE_ORDER` に 1 つだけあり、`/api/sites` と SSR のカテゴリ一覧が共有する。`app.js` は並べ替えず、API の順を保って絞り込む（検索結果も同じ並び）。ピックアップ（ランダム）は対象外。並び順の切替 UI はない（意味検索・マッチ度とセットで構想: [ideas/scope-and-search.md](../ideas/scope-and-search.md)）。

更新日の取得は [procedures.md](../collection/procedures.md#サイトの更新日の取得)。

## ピックアップ

トップで、掲載サイトから最大 3 件をランダムに選び、1 件ずつ 8 秒ごとに表示する。画面外・非表示タブ・フォーカス中・ポインター上・アニメーション軽減設定では自動切替を止める。ファビコンは一覧と同じものを表示する。将来 NEW や確認可能な更新頻度を選出に使う構想があるが、十分な更新履歴や信頼できる日時が揃うまで使わない。人気や閲覧数は使わない。

## NEW タグ

登録日時（`sites.registered_at`）から 30 日未満のサイトに NEW を付ける（期間は仮。未決）。登録日時が不明なサイトには付けない。新規 INSERT 時は DB のトリガ（migration 0006）が時刻を記録する。

## HUD

画面幅 1200px 以上で表示する（それ未満は非表示）。

- 左上（SITE INDEX）: D1 の実データから、掲載総数と直近 7 日の日別登録数だけを表示する。日別は連続した横バー 1 行固定で、長さは表示範囲の最大日を 100% として正規化する。0 件の日は幅 0、1 件以上は最小幅 3px。凡例は出さない。登録日が不明なサイトは日別に含めない。内部事情（日付不明の件数など）は表示しない。
- 左下（ACTIVITY）: このブラウザで実際に行ったカテゴリ移動（`cd`）・検索（`search`）・地球操作（`fly`）を端末風に表示する。新しい行が下に追加され、最大 5 行。画面内のみで、保存・外部送信しない。シェルを実行する機能ではない。

アクセス数や人気順は使わない。

## ファビコン

元サイトで確認したものをローカル配信する（`sites.favicon_path`、`public/icons/`）。未取得・失敗時は何も表示せず、表示時に第三者のサーバーへ問い合わせない。

## 言語

既定は英語。`localStorage` の `mise-language` が `ja` のときだけ日本語になる。ブラウザ言語での自動判定はしない。サイトの紹介文は `description_en`（英語）と `description_ja` を持ち、英語表示で `description_en` が無いサイトだけ日本語に「(Japanese)」を添える（SSR と `app.js` で同じ扱い）。

## ロゴ

大文字の太い縦長ゴシック体 `MISE`。三毛猫模様のグラデーション。ホバー・フォーカスで模様の境界がなだらかにぼける（`@property --blur` による補間。`prefers-reduced-motion` では即時。`@property` 非対応のブラウザでは補間されず、ホバーで即時にぼける。`@supports` の分岐はない）。M/S の横伸ばしはインラインスクリプトで初回描画前に適用し、通常幅の瞬間を見せない。タイトル下に発音記号 `/ˈmiːseɪ/` を小さく出す。
